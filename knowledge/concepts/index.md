# Concept

* [Bundle y Concepto — las unidades de OKF](bundle-and-concept.md) - Un bundle es la carpeta knowledge/; un concepto es un .md con frontmatter.
* [Progressive disclosure](progressive-disclosure.md) - El agente ve un mapa chico (index.md) y baja solo a los conceptos que necesita.
* [Perfiles — cómo OKF se adapta a cualquier dominio](profiles.md) - Un perfil es un layout de carpetas + un vocabulario de type, según el dominio.
* [El ciclo de vida del contexto (init y mantenimiento)](lifecycle.md) - El bundle se monta una vez (init) y se mantiene vivo incremental para no pudrirse.
